# ResearchGrid — Academic Research Portal

Static 5-page website concept.

## Design
- Sharp-edged editorial layout
- No shadows
- No blue theme
- Barlow Condensed typography
- LTR
- Responsive

## Pages
Home, Research, Projects & Datasets, Researchers & Conferences, About.

## Images
Remote Unsplash images are used in the static HTML. Image credit is shown where applicable.
